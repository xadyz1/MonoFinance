# MonoFinance Mobile (Android)

Нативний Android-додаток для зручного та швидкого внесення витрат у ваш акаунт MonoFinance за допомогою голосового введення українською мовою.

## Функціонал

1. **Авторизація та синхронізація**:
   - Повна підтримка авторизації у вашому акаунті на Flask-сервері.
   - Збереження сесії та кук через захищене локальне сховище (SharedPreferences).
   - Відображення останніх 10 транзакцій прямо на головному екрані додатку.

2. **Підключення до сервера**:
   - Можливість вказати власну адресу сервера в налаштуваннях (за замовчуванням встановлено https://finance.swiftapps.cloud).

3. **Голосове введення витрат**:
   - Запис та розпізнавання мовлення через нативну службу Android SpeechRecognizer.
   - Розпізнає мову українською мовою.
   - Працює з незахищеними з'єднаннями HTTP (на відміну від Web Speech API у мобільних браузерах, яке блокується політикою безпеки).

4. **Розумний парсинг тексту**:
   - Автоматично розпізнає суми, записані цифрами (наприклад, "120") або словами (наприклад, "сто двадцять п'ять").
   - Вилучає зайві дієслова та прийменники (наприклад, "купив", "заплатив", "за", "на") та формує назву транзакції.
   - Автоматично заповнює форму, дозволяючи користувачу змінити опис, суму чи категорію (Витрата, Дохід, Накопичення) перед збереженням.

## Системні вимоги

- Android SDK 21+ (Android 5.0 та новіші версії).
- Доступ до мікрофона (запитується при першому голосовому введенні).
- Підключення до інтернету.

## Як зібрати та запустити додаток

1. **Через Android Studio (Рекомендовано)**:
   - Запустіть Android Studio.
   - Оберіть "Open" та вкажіть шлях до папки `MonoFinanceAndroid`.
   - Android Studio автоматично завантажить потрібні версії Gradle та залежностей.
   - Підключіть Android-пристрій через USB (з увімкненим режимом налагодження) або запустіть емулятор.
   - Натисніть кнопку "Run" (зелений трикутник) для збірки та запуску додатка на пристрої.

2. **Збірка через командний рядок (Windows)**:
   - Відкрийте консоль у папці `MonoFinanceAndroid`.
   - Виконайте команду: `.\gradlew assembleDebug` (при першому запуску Gradle автоматично завантажиться).
   - Готовий файл APK буде розміщено за шляхом: `app/build/outputs/apk/debug/app-debug.apk`.
